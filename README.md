# Linux Systems Lab

A small private lab for practicing Linux, shell scripting and C system programming.

This repository contains selected exercises and small experiments from my system programming coursework, cleaned up and documented as personal practice material.

The focus is on command-line work, Bash scripting, Makefiles, C programming, file I/O, file descriptors, permissions, filesystem metadata and small Unix-like utilities.

This is not meant to be one large application. It is a compact lab for building the fundamentals behind Linux-based software, infrastructure and embedded-adjacent work.

## Topics

- Bash scripting
- Linux command-line workflows
- Makefiles
- C programming
- low-level file I/O
- file descriptors
- permissions and file metadata
- simple Unix-tool reimplementations
- basic debugging and inspection tools

## Structure

- `shell-basics/` - small Bash scripts and command-line exercises
- `c-basics/` - basic C programs and Makefile usage
- `file-io/` - file input/output exercises in C
- `filesystem/` - file attributes, file size and link-related exercises
- `debugging-and-tools/` - small exercises around compiled programs and inspection tools
- `notes/` - short notes about what I learned

## Note

This repository does not include official course sheets or task descriptions. It only contains my own cleaned-up code and personal notes.
